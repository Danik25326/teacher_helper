# 📚 Перевірка ДЗ — Алгебра & Геометрія (НУШ)

Локальний сайт для перевірки домашніх робіт учнів за допомогою ШІ.  
Оцінює за **10-бальною системою НУШ**, дає поради та показує скільки токенів витрачено.

---

## 🚀 Як запустити

### 1. Клонуйте репозиторій
```bash
git clone https://github.com/ВАШ-НІКНЕЙМ/teacher-checker.git
cd teacher-checker
```

### 2. Додайте API ключ
```bash
cp config.example.js config.js
```
Відкрийте `config.js` і вставте свій Groq API ключ.

### 3. Відкрийте сайт
Просто відкрийте `index.html` у браузері (Chrome/Edge рекомендовано).  
Або через VS Code → Live Server.

## ⚙️ Модель і ліміти

- **Модель:** `openai/gpt-oss-120b` (через Groq)
- **Ліміт:** 30 запитів/хв · 1000/день · 8K токенів/хв · 200K токенів/день
